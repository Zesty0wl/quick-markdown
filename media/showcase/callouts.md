# Callouts, the GitHub way

> [!NOTE]
> Quick Markdown renders GitHub's alerts with the same colours and icons.

> [!TIP]
> Point it at the file your agent is writing and watch it update live.

> [!IMPORTANT]
> Your scroll position survives every edit, even mid-sentence.

> [!WARNING]
> Scripts in a document are shown as text, never run.

> [!CAUTION]
> May cause you to stop opening Markdown in a text editor.
